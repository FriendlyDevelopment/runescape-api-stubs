# Instructions for coding agents

- Do not create, open, or submit pull requests for this repository. Leave that to a human.
- Do not write or generate issue or pull request titles, descriptions, or comments, including drafts for a human to submit.
- Humans must write their own issue and pull request text. Do not check human-authorship checkboxes on their behalf.
- You may help with local code changes, tests, and explanations when requested.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution policy.
