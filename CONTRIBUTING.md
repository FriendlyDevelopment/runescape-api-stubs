# Contributing

Humans must open pull requests themselves and write their own issue and pull request titles, descriptions, and comments. Do not submit AI-generated text, even if you have reviewed or edited it.

AI tools may assist with local code changes, tests, and understanding the codebase, but must not open pull requests or write contribution text on your behalf. This keeps the discussion in the contributor's own words and makes responsibility for the contribution clear.

When opening an issue, please confirm that you are human and have written the text yourself.

Please keep things brief and to the point though if there's a lot of changes of course it makes sense for your description to be longer.
